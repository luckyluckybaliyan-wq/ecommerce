
# Ecommerce Project

A full-stack ecommerce application built with React (Vite) for the frontend and Django for the backend.

## Features

- User registration and login
- Product listing and product details
- Shopping cart
- Checkout
- Password reset

## Tech Stack

**Frontend:** React, Vite, JavaScript, CSS

**Backend:** Python, Django

**Database:** Configure according to your project settings.


## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

Open a separate terminal:

```bash
cd backend
python manage.py runserver
```

Install the backend dependencies and configure environment variables before starting the server.
